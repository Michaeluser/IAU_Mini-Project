# Household Electric Power Consumption Forecasting

This project focuses on predicting household electric power consumption using machine learning and deep learning models.

## Dataset

Dataset used in this project:

* [Individual Household Electric Power Consumption Dataset](https://www.kaggle.com/datasets/uciml/electric-power-consumption-data-set)

The dataset contains household electricity usage measurements collected over time.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* TensorFlow / Keras
* XGBoost
* Matplotlib

## What the Project Includes

* Data cleaning and preprocessing
* Exploratory data analysis
* Feature selection
* Data normalization and transformations
* Machine learning models
* LSTM neural network
* Model evaluation and comparison

## Models Used

* Linear Regression
* Ridge Regression
* Elastic Net Regression
* XGBoost Regressor
* LSTM Neural Network

## Evaluation Metrics

The models are evaluated using:

* Mean Squared Error (MSE)
* Mean Absolute Error (MAE)
* R² Score
